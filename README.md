# עבריולדת — חבילת המשך לקודקס

זוהי חבילת מסירה מלאה של האתר **עבריולדת**. היא כוללת את קוד האתר שפועל כעת, את ספריית חישוב התאריכים העבריים, מסמכי פרטיות ותנאים, בדיקת תקינות, הוראות פרסום ומסמך הקשר מפורט לקודקס.

האתר הפעיל בעת יצירת החבילה: <https://ivriyomhuledet.elad.chatgpt.site>

## הדרך הקצרה להמשיך בקודקס

1. העלה לקודקס את קובץ ה־ZIP הזה כפי שהוא.
2. כתוב לקודקס:

   > חלץ את החבילה, קרא קודם את `AGENTS.md` ואת `CODEX_HANDOFF.md`, בדוק שהאתר עובד, ואז המשך לפתח אותו לפי הבקשה שלי. אל תיצור אתר חדש ואל תשנה את מזהה הפרויקט הקיים.

3. לאחר מכן תוכל לבקש שינוי רגיל, למשל: "חבר את Google Calendar", "הוסף יבוא מקובץ", או "שפר את מסך הרשימה".

## הרצה מקומית

אין שלב build ואין צורך להתקין חבילות. נדרש רק שרת קבצים מקומי, מפני שהאתר משתמש ב־JavaScript Modules:

```bash
python3 -m http.server 8000 --directory dist
```

לאחר מכן פתח: <http://localhost:8000>

בדיקת תקינות מהירה:

```bash
node scripts/verify.mjs
```

## מבנה החבילה

- `dist/` — כל קוד האתר המוכן לפרסום.
- `dist/calendar.js` — המרת תאריכים, תאריכי יום הולדת עתידיים, ICS ואירועי Google.
- `dist/google-calendar.js` — חיבור OAuth וסנכרון ל־Google Calendar.
- `dist/app.js` — התנהגות המסכים, טפסים, הרשימה ושמירה מקומית.
- `dist/vendor/hdate/` — העתק מקומי של `@hebcal/hdate` והרישיון שלו.
- `CODEX_HANDOFF.md` — מצב המוצר, החלטות טכניות, מה חסר ואיך ממשיכים.
- `RESEARCH.md` — מקורות המחקר הרשמיים שעליהם נשענות ההחלטות.
- `AGENTS.md` — הוראות עבודה לקודקס בתוך הפרויקט.
- `.github/workflows/pages.yml` — פרסום אופציונלי ב־GitHub Pages.
- `.openai/hosting.json` — הקישור לפרויקט Sites הקיים; אסור להחליף את ה־`project_id` אם ממשיכים את האתר הקיים.

## דבר אחד שעדיין דורש הגדרה

חיבור Google Calendar כבר ממומש בקוד, אך כפתור החיבור מושבת מפני שלא הוגדר עדיין Google OAuth Client ID. ההוראות המלאות נמצאות ב־`CODEX_HANDOFF.md` תחת "הפעלת Google Calendar".

חשוב: בדפדפן מותר לשים **Client ID בלבד**. אין להוסיף Client Secret, מפתח פרטי, סיסמה או token לקוד או ל־GitHub.

## פרטיות

רשימת האנשים נשמרת כרגע רק ב־`localStorage` של הדפדפן. אין בחבילה נתוני משתמשים, חשבונות Google, אסימוני גישה או סודות. אסימון Google נשמר בזיכרון בלבד ונעלם ברענון הדף.

## GitHub

אפשר לפתוח repository חדש, להעלות אליו את תוכן התיקייה, להפעיל GitHub Pages במצב **GitHub Actions**, ולדחוף ל־`main`. ה־workflow המצורף יפרסם את `dist/`. אם משתמשים בדומיין של GitHub Pages, צריך להוסיף גם אותו כ־Authorized JavaScript origin ב־Google Cloud.

לפני הפיכת המאגר לציבורי, בחר רישיון לקוד המקורי. רישיון התלות `@hebcal/hdate` כבר כלול בתיקיית הספק.
